# LUXEury — Ultra Exclusive Access

**By Invitation Only · For Ultra High Net Worth Individuals**

LUXEury is the world's most exclusive private members' platform, curated for UHNWI.

## Features

- **Hotels & Resorts** — US & International 5–6 star hotels, Michelin Key recognised properties
- **Penthouses & Villas** — Sky-high penthouses, historic villas, private island estates
- **Fine Dining** — Michelin 1–3 star restaurants and extraordinary culinary experiences
- **Luxury Shopping** — Private ateliers, flagship boutiques, premier shopping districts
- **Membership** — Two-tier invite-only programme: Obsidian & Black Diamond

## Tech Stack

- **Next.js 14** (App Router) · **TypeScript** · **Tailwind CSS**
- Google Fonts: Playfair Display, Cormorant Garamond, Inter
